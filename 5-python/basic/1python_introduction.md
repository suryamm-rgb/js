# What is Python?

Python is a **popular programming language**. It was created by **Guido van Rossum**, and released in **1991**.

It is used for:
- **Web development** (server-side)
- **Software development**
- **Mathematics**
- **System scripting**

---

## What can Python do?

Python can be used for:
- Creating **web applications** on a server
- Creating **workflows** alongside other software
- Connecting to **database systems**
- **Reading and modifying files**
- Handling **big data** and performing **complex mathematics**
- **Rapid prototyping** and **production-ready software development**

---

## Why Python?

Python is popular because:
- It works on different platforms (**Windows, Mac, Linux, Raspberry Pi**, etc.)
- It has a **simple syntax** similar to the English language
- Developers can write programs in **fewer lines** than many other programming languages
- It runs on an **interpreter system**, meaning code can run as soon as it is written
- It supports **procedural**, **object-oriented**, and **functional** programming styles

---

---

## Python syntax compared to other programming languages

Python was designed for **readability**, with similarities to the English language and some influence from mathematics.

### Key syntax features
- Python uses **new lines** to complete a command  
  (other languages often use semicolons `;` or parentheses)
- Python relies on **indentation (whitespace)** to define scope (loops, functions, classes)  
  (other languages often use **curly braces `{}`**)

# JavaScript Array Methods Reference

| Name              | Description                                                             |
| ----------------- | ----------------------------------------------------------------------- |
| `[ ]`             | Creates a new Array                                                     |
| `new Array()`     | Creates a new Array                                                     |
| `at()`            | Returns an indexed element of an array                                  |
| `concat()`        | Joins arrays and returns an array with the joined arrays                |
| `constructor`     | Returns the function that created the Array prototype                   |
| `copyWithin()`    | Copies array elements within the array, to and from specified positions |
| `entries()`       | Returns a key/value pair Array Iteration Object                         |
| `every()`         | Checks if every element in an array passes a test                       |
| `fill()`          | Fills the elements in an array with a static value                      |
| `filter()`        | Creates a new array with every element that passes a test               |
| `find()`          | Returns the value of the first element that passes a test               |
| `findIndex()`     | Returns the index of the first element that passes a test               |
| `findLast()`      | Returns the value of the last element that passes a test                |
| `findLastIndex()` | Returns the index of the last element that passes a test                |
| `flat()`          | Concatenates sub-array elements                                         |
| `flatMap()`       | Maps all array elements and creates a new flat array                    |
| `forEach()`       | Calls a function for each array element                                 |
| `from()`          | Creates an array from an object                                         |
| `includes()`      | Checks if an array contains the specified element                       |
| `indexOf()`       | Searches the array for an element and returns its position              |
| `isArray()`       | Checks whether an object is an array                                    |
| `join()`          | Joins all elements of an array into a string                            |
| `keys()`          | Returns an Array Iteration Object containing the keys                   |
| `lastIndexOf()`   | Searches the array from the end and returns its position                |
| `length`          | Sets or returns the number of elements in an array                      |
| `map()`           | Creates a new array with results of a function call on each element     |
| `of()`            | Creates an array from a number of arguments                             |
| `pop()`           | Removes the last element and returns it                                 |
| `prototype`       | Allows adding properties and methods to an Array object                 |
| `push()`          | Adds new elements to the end and returns the new length                 |
| `reduce()`        | Reduces values to a single value (left-to-right)                        |
| `reduceRight()`   | Reduces values to a single value (right-to-left)                        |
| `reverse()`       | Reverses the order of elements                                          |
| `shift()`         | Removes the first element and returns it                                |
| `slice()`         | Selects part of an array and returns a new array                        |
| `some()`          | Checks if any element passes a test                                     |
| `sort()`          | Sorts the elements of an array                                          |
| `splice()`        | Adds or removes array elements                                          |
| `toReversed()`    | Reverses elements into a new array                                      |
| `toSorted()`      | Sorts elements into a new array                                         |
| `toSpliced()`     | Adds or removes elements into a new array                               |
| `toString()`      | Converts an array to a string                                           |
| `unshift()`       | Adds new elements to the beginning and returns the new length           |
| `valueOf()`       | Returns the primitive value of an array                                 |
| `with()`          | Returns a new array with updated elements                               |

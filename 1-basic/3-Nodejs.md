# what is Node.js

- Node.js is an open-source,cross-platform JavaScript runtime environment
- **Open Source** - source code is publicly available for sharing and modification
- **Cross Platform** - available on Mac, Windows and Linux
- **JavaScript runtime environment** - provides all the necessary components in order to use and run a JavaScript program outside the browser

## what can you build with Node.js?

- Traditional websites
- Backend services like APIs
- Real-time application
- Streaming services
- CLI tools
- Multiplayer games
- Node.js allows you to build complex and powerful applications

> [!NOTE]
> UV which is an open source Library used in node called **libue** this is another major dependency providing node.js access to underlying operating system features like file and networking >
